# ГлазУх

**Офлайн-first помощник доступности для Android.** Проект задуман для незрячих, слабовидящих, глухих и слабослышащих людей. Цель — использовать обычный Android-смартфон вместо обязательной покупки специальных очков.

> **Статус: ранняя альфа (0.1.0).** Это начальная рабочая основа, а не готовое медицинское или навигационное устройство. Функции, которых ещё нет, прямо перечислены ниже.

## Что уже заложено в код

### Чтение текста камерой
- Нативный Android-интерфейс с CameraX.
- Офлайн OCR на Tesseract 5 через [Tesseract4Android](https://github.com/adaptech-cz/Tesseract4Android).
- Русская и английская языковые модели загружаются по HTTPS в первый запуск и хранятся в приватной папке приложения.
- После загрузки моделей распознавание выполняется локально, без отправки фотографии в облако.
- Результат можно прослушать через Android TextToSpeech; длинные тексты безопасно делятся на фрагменты.

### Распознавание предметов
- Локальный EfficientDet-Lite0 через MediaPipe Tasks Vision.
- Модель (~13.8 MB) загружается по запросу, хранится в приватной папке и проверяется по закреплённому SHA-256.
- Поддерживается разовый снимок и непрерывный анализ камеры с ограничением частоты кадров.
- Голосовые объявления фильтруются по нескольким последовательным кадрам, чтобы не повторять одну категорию на каждом кадре.
- Поддерживаются 80 категорий COCO; русские названия формируются локально.
- COCO обнаруживает категорию «traffic light», но не определяет сигнал пешеходу, фазу перехода, цвет лампы с требуемой точностью или безопасность пересечения дороги.

### Живые субтитры
- Используется `SpeechRecognizer.createOnDeviceSpeechRecognizer()` на Android 12+.
- Облачный fallback намеренно отсутствует.
- Доступно переключение русского и английского языка, если соответствующий локальный системный движок установлен.
- Если системный локальный движок не установлен или не поддерживает нужный язык, приложение сообщает об этом вместо скрытой отправки аудио в сеть.
- В полной сборке дополнительно доступен русский потоковый движок T-one через sherpa-onnx. Его модель (~144 МБ) загружается только после явного выбора пользователем и после проверки SHA-256; дальнейшее распознавание полностью локальное.
- Облегчённая Lite-сборка не содержит sherpa-onnx runtime и его нативную библиотеку; системные субтитры и остальные возможности остаются доступны.

### Доступность и приватность
- Крупные контрастные кнопки и крупный текст.
- Статусные сообщения публикуются как live region для средств доступности.
- Фото сохраняется только во временном файле кеша и удаляется после обработки.
- Нет регистрации, рекламного SDK, аналитики или обязательного API-ключа.
- Разрешения камеры и микрофона запрашиваются только при входе в соответствующий режим.

## Что пока НЕ реализовано

- Автоматическое определение срока годности, названия лекарства и дозировки как структурированных полей. Сейчас приложение читает распознанный текст; оно не делает медицинские выводы.
- Распознавание банкнот.
- Определение цвета/состояния светофора, безопасного момента перехода и дорожная навигация.
- Свободный вопрос к сцене («что у меня в руке?») и подключение внешних веб-моделей.
- Надёжная непрерывная транскрипция на устройствах без системного on-device speech provider.
- Привязка каждой фразы живых субтитров к голосу в реальном времени пока не реализована. В Full добавлен отдельный офлайн-анализ короткой записи: до 3 минут аудио в памяти, затем временные интервалы «Собеседник 1», «Собеседник 2» и т. д. Запись не сохраняется в файл и удаляется из памяти после анализа. Первое использование скачивает две проверяемые модели (~47 МБ).
- Автоматическое переключение между несколькими офлайн-моделями речи.

Эти функции требуют отдельных моделей, оценки скорости на бюджетных устройствах, тестов в реальных условиях и отдельного согласия на отправку данных для сетевых функций. Нельзя заявлять, что уже работающий OCR умеет распознавать дозировки или что системные субтитры различают людей.

## Технологии

- Kotlin, Jetpack Compose, Material 3.
- CameraX 1.6.2.
- MediaPipe Tasks Vision 1.2.2 и EfficientDet-Lite0.
- Tesseract OCR 5 через Tesseract4Android.
- Модели [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast).
- Android TextToSpeech.
- Android on-device SpeechRecognizer.
- Два варианта сборки: Lite (без sherpa-onnx runtime) и Full (русский T-one ASR и офлайн-разделение собеседников).
- GitHub Actions для сборки APK.

Для офлайн-разделения собеседников Full использует Kotlin API [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx), pyannote segmentation и 3D-Speaker embeddings. Модели загружаются по запросу, проверяются по размеру и SHA-256, а анализ выполняется локально. Это экспериментальная диаризация голосовых фрагментов, не идентификация людей.

## Сборка

Требования:
- Android Studio с Android SDK Platform 36.
- JDK 17.
- Gradle 8.13.

Откройте проект в Android Studio либо выполните в среде с установленным Gradle:

```bash
# Облегчённая версия без дополнительного speech runtime
gradle assembleLiteDebug

# Полная версия с русским потоковым ASR T-one и диаризацией
gradle assembleFullDebug
```

APK появятся в `app/build/outputs/apk/lite/debug/` и `app/build/outputs/apk/full/debug/`. Lite и Full используют разные applicationId, поэтому их можно установить рядом.


GitHub Actions собирает debug APK при push в `main`, при pull request и вручную через workflow_dispatch.

## Первое использование

1. Установите debug APK.
2. Откройте «Прочитать текст камерой» и разрешите доступ к камере.
3. При первом распознавании приложение скачает `rus.traineddata` и `eng.traineddata` из `tessdata_fast`.
4. При первом запуске распознавания предметов приложение скачает проверенную модель EfficientDet-Lite0 (около 13.8 MB).
5. После загрузки моделей можно отключить интернет: OCR и детектор предметов продолжат работать локально.
6. В Lite для субтитров доступен системный локальный движок Android. В Full можно дополнительно выбрать русский T-one; при первом запуске потребуется скачать модель около 144 МБ.\n7. В Full откройте «Разделить собеседников · офлайн», запишите разговор (до 3 минут) и остановите запись для анализа. При первом использовании скачаются модели диаризации (~47 МБ).

## Важное предупреждение

ГлазУх — вспомогательный инструмент. OCR, распознавание предметов и речи могут ошибаться. Не полагайтесь на приложение как на единственный источник информации о лекарстве, дозировке, сроке годности, банкноте, дорожном сигнале или безопасности перехода. Для критических решений нужна проверка человеком или надёжным независимым способом.
