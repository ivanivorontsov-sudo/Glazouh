## Что реализовано в прототипе (это не подтверждение работоспособности)

### Чтение текста камерой
- Нативный Android-интерфейс с CameraX.
- Офлайн OCR на Tesseract 5 через [Tesseract4Android](https://github.com/adaptech-cz/Tesseract4Android).
- Русская и английская языковые модели загружаются по HTTPS в первый запуск и хранятся в приватной папке приложения.
- После загрузки моделей распознавание выполняется локально, без отправки фотографии в облако.
- Результат можно прослушать через Android TextToSpeech.

### Живые субтитры
- Используется \`SpeechRecognizer.createOnDeviceSpeechRecognizer()\` на Android 12+.
- Облачный fallback намеренно отсутствует.
- Если системный локальный движок не установлен или не поддерживает нужный язык, приложение сообщает об этом вместо скрытой отправки аудио в сеть.

### Доступность и приватность
- Крупные контрастные кнопки и крупный текст.
- Статусные сообщения публикуются как live region для средств доступности.
- Фото сохраняется только во временном файле кеша и удаляется после обработки.
- Нет регистрации, рекламного SDK, аналитики или обязательного API-ключа.
- Разрешения камеры и микрофона запрашиваются только при входе в соответствующий режим.

## Что пока НЕ реализовано

- Автоматическое определение срока годности, названия лекарства и дозировки как структурированных полей. Сейчас приложение читает распознанный текст; оно не делает медицинские выводы.
- Распознавание банкнот.
- Распознавание светофоров, дорожных знаков и безопасного момента перехода.
- Свободный вопрос к сцене («что у меня в руке?») и подключение внешних веб-моделей.
- Надёжная непрерывная транскрипция на устройствах без системного on-device speech provider.
- Диаризация и идентификация говорящих («кто именно произнёс фразу»).
- Автоматическое переключение между несколькими офлайн-моделями речи.

Эти функции требуют отдельных моделей, оценки скорости на бюджетных устройствах, тестов в реальных условиях и отдельного согласия на отправку данных для сетевых функций. Нельзя заявлять, что уже работающий OCR умеет распознавать дозировки или что системные субтитры различают людей.

## Технологии

- Kotlin, Jetpack Compose, Material 3.
- CameraX 1.6.2.
- Tesseract OCR 5 через Tesseract4Android.
- Модели [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast).
- Android TextToSpeech.
- Android on-device SpeechRecognizer.
- GitHub Actions для сборки APK.

Для будущей офлайн-диаризации рассматривается [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx): у проекта есть Android-поддержка ASR, TTS и speaker diarization. Это пока планируемый адаптер, а не включённая функция Glazouh.

## Сборка

Требования:
- Android Studio с Android SDK Platform 36.
- JDK 17.
- Gradle 8.13.

Откройте проект в Android Studio либо выполните в среде с установленным Gradle:

\`\`\`bash
gradle assembleDebug
\`\`\`

APK появится в \`app/build/outputs/apk/debug/\`.

GitHub Actions собирает debug APK при push в \`main\`, при pull request и вручную через workflow_dispatch.

## Проверка проекта разработчиком

1. Не устанавливайте APK на устройство, используемое для передвижения или повседневной безопасности. Тестирование допустимо только в полностью безопасной домашней обстановке, без движения и опасных факторов.
2. Откройте «Прочитать текст камерой» и разрешите доступ к камере.
3. При первом распознавании приложение скачает \`rus.traineddata\` и \`eng.traineddata\` из \`tessdata_fast\`.
4. После загрузки моделей можно отключить интернет: OCR продолжит работать локально.
5. Для субтитров разрешите микрофон и проверьте, доступен ли на устройстве локальный русский движок речи.

## Важное предупреждение

Это не готовое приложение и не сертифицированное средство технической реабилитации. Полноценные испытания точности, надёжности, безопасности, доступности и совместимости не проводились. OCR может пропускать, искажать или придумывать текст; распознавание речи может ошибаться или не работать на конкретном устройстве.

**Никаких дорожных и навигационных сценариев:** приложение нельзя использовать для перехода дороги, оценки дорожной обстановки, движения по улице, навигации, обхода препятствий, подъёма/спуска по лестнице или любой деятельности, где ошибка может привести к травме. Не используйте его рядом с транспортом, огнём, водой, высотой, острыми предметами и механизмами. Только неподвижные, абсолютно безопасные проверки внутри дома. Не полагайтесь на него при приёме лекарств, экстренной связи или других критических решениях.

Перед любым тестом изучите исходный код, зависимости, разрешения и загружаемые модели. Даже успешная сборка APK не доказывает корректность работы. Если нет возможности обеспечить полностью безопасные условия, не запускайте проект.
